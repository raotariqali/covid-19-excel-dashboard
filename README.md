## 📌 Project Overview

The **COVID-19 Executive Dashboard** is an interactive data analytics project developed using **Microsoft Excel**.

The project transforms COVID-19 data into an executive-style dashboard that enables users to explore:

- COVID-19 cases
- Deaths
- Recoveries
- Active cases
- Testing
- Country-level comparisons
- Regional analysis
- Monthly trends
- Population-adjusted metrics

Interactive slicers allow users to dynamically filter the dashboard by **Date, Continent, and WHO Region**.

This project demonstrates practical experience in **data analysis, dashboard development, KPI reporting, PivotTables, PivotCharts, interactive filtering, and data visualization**.

# 🎯 Project Objectives

The main objectives of this project are to:

- Analyze COVID-19 cases, deaths, recoveries, active cases, and testing data
- Monitor important COVID-19 performance indicators
- Analyze monthly case and death trends
- Compare countries using per-million metrics
- Analyze deaths across WHO regions
- Build an interactive Excel dashboard
- Use PivotTables and PivotCharts for analytical reporting
- Create an executive-friendly dashboard
- Present complex information through meaningful visualizations

---

# 📊 Key Performance Indicators

The dashboard contains **5 major KPI cards**.

| KPI | Description |
|---|---|
| 🧪 **Total Tests** | Total COVID-19 tests recorded |
| 🦠 **Total Cases** | Total confirmed COVID-19 cases |
| ⚰️ **Total Deaths** | Total reported COVID-19 deaths |
| 💚 **Total Recovered** | Total recovered COVID-19 cases |
| 🔴 **Total Active Cases** | Total active COVID-19 cases |

These KPIs provide a quick executive-level overview of the dataset.
